# 集群管理页面布局设计文档

> 状态：设计阶段（待评审） · 适用页面：`Components/Pages/Clusters.razor`
> 本文档只描述页面布局与视觉结构，不给出具体实现代码。

---

## 1. 设计目标与布局策略

新布局把「浏览 / 定位 / 管理」三种行为分层处理：左侧分组侧边栏负责快速切换业务分组，顶部工具栏负责搜索、过滤、视图切换与排序，主内容区则根据当前视图以卡片（扫视优先）或表格（效率优先）展示集群。通过清晰的区域分工，让最常用的「添加集群」「搜索名称」「切换视图」三项动作在首屏直接可达，同时避免工具栏因控件过多而压过内容。

---

## 2. 整体布局结构

页面在 `MainLayout` 的 `MudMainContent > MudContainer MaxWidth=False` 内渲染，不改变应用外壳（AppBar / Mini Drawer）。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [MudText h4] 集群管理                                                   │
├──────────────┬──────────────────────────────────────────────────────────┤
│              │  ┌────────────────────────────────────────────────────┐  │
│              │  │ 标题区：分组名称 + 集群数量                    [添加集群] │  │
│  分组侧边栏   │  ├────────────────────────────────────────────────────┤  │
│  (sticky)    │  │ 工具栏：搜索 | 状态 | 版本 | [重置] [卡片/表格] [排序▼] │  │
│              │  ├────────────────────────────────────────────────────┤  │
│              │  │                                                      │  │
│              │  │                  列表区域                            │  │
│              │  │           （卡片网格 或 MudTable）                    │  │
│              │  │                                                      │  │
│              │  └────────────────────────────────────────────────────┘  │
└──────────────┴──────────────────────────────────────────────────────────┘
```

### 区域说明

| 区域 | 宽度/行为 | 主要组件 |
|------|-----------|----------|
| 页面标题 | 全宽，位于两列之上 | `MudText Typo="Typo.h4"` |
| 分组侧边栏 | 桌面 260px，sticky 顶部；移动端全宽堆叠 | 自定义 div + `MudText` + `MudBadge` + `MudIconButton` |
| 内容区 | 弹性剩余宽度 | `MudGrid` / `MudTable` |
| 标题区 | 内容区最上方一行 | `MudText` + `MudButton` |
| 工具栏 | 标题区下方一行/多行 | `MudTextField` + `MudSelect` + `MudButton` + `MudToggleGroup` |
| 列表区 | 工具栏下方，占据内容区剩余空间 | `MudGrid` 或 `MudTable` |

## 3. 工具栏区设计

### 3.1 布局安排：两行式

| 行 | 左侧 | 右侧 | 理由 |
|----|------|------|------|
| 第一行 | 当前分组名 + 集群数量 | 「添加集群」按钮 | 明确当前上下文，并让最核心的创建动作常驻右上角 |
| 第二行 | 搜索 + 状态 + 版本 + 重置 | 视图切换 + 排序 | 过滤控件天然聚类；视图与排序是展示方式而非数据过滤，放在右侧 |

第二行在桌面端尽量一行排列；控件过多或屏幕变窄时允许自然换行（使用 flex wrap）。

### 3.2 控件明细

| 控件 | 组件 | 位置/尺寸 | 行为 |
|------|------|-----------|------|
| 分组标题 | `MudText Typo="Typo.h5"` | 第一行左侧 | 显示当前选中的分组名（"全部集群"或分组名） |
| 数量副标题 | `MudText Typo="Typo.body2"` | 标题下方 | "共 N 个集群"，应用 `mud-text-secondary` |
| 添加集群按钮 | `MudButton` `Variant="Variant.Filled"` `Color="Color.Primary"` | 第一行右侧 | `StartIcon="@Icons.Material.Filled.Add"`，点击打开 `AddClusterDialog` |
| 名称搜索 | `MudTextField` | 第二行最左侧，flex 1，min-width 200px | `Adornment="Adornment.Start"` 搜索图标，`Placeholder="搜索集群名称"`，实时过滤建议防抖 300ms |
| 状态筛选 | `MudSelect<T="ClusterStatus?">` | 第二行，width 140px | 选项：全部 / 在线 / 离线 / 未知；`Dense="true"` |
| 版本筛选 | `MudSelect<T="string?">` | 第二行，width 160px | 选项来自当前集群 distinct `Version`，null 显示为"未知"；`Dense="true"` |
| 重置按钮 | `MudButton` `Variant="Variant.Text"` `Color="Color.Secondary"` | 第二行，筛选控件右侧 | 清空名称、状态、版本三个条件；分组由侧边栏控制，不参与重置 |
| 视图切换 | `MudToggleGroup<T="ViewMode">` | 第二行右侧 | 两个选项：卡片 `Icons.Material.Filled.GridView` / 表格 `Icons.Material.Filled.TableRows`，默认卡片 |
| 排序下拉 | `MudSelect<T="SortOption">` | 视图切换右侧或下方 | 卡片视图下显示；表格视图隐藏，改为表头排序 |

### 3.3 排序下拉（仅卡片视图）

使用单个 `MudSelect` 承载「字段 + 方向」的复合选项，避免占用两列空间：

- 名称升序 / 名称降序
- 状态升序 / 状态降序
- 节点数升序 / 节点数降序
- 创建时间升序 / 创建时间降序

默认「创建时间降序」（最新的在前）。

## 4. 卡片视图设计

### 4.1 网格响应式

使用 `MudGrid Spacing="3"` + `MudItem`：

| 断点 | 列数 | MudItem 属性 |
|------|------|--------------|
| xs (<600px) | 1 | `xs="12"` |
| sm (600-960px) | 2 | `sm="6"` |
| md (960-1280px) | 3 | `md="4"` |
| lg (≥1280px) | 4 | `lg="3"` |

### 4.2 单张卡片结构

每张卡片使用 `MudCard Elevation="2"`，整体可点击跳转详情；操作按钮阻止事件冒泡。

```
┌─────────────────────────────────────────┐
│  [名称]                    [状态chip]   │  ← MudCardHeader
├─────────────────────────────────────────┤
│  上次检查：3 分钟前                      │  ← MudCardContent 顶部
│                                         │
│  版本        v1.28.4                    │
│  节点数      5                          │
│  分组        生产环境                    │
│  API Server  https://... (截断)         │
│  创建时间    2024-01-15 09:30           │
├─────────────────────────────────────────┤
│ [刷新] [编辑]                [删除]     │  ← MudCardActions
└─────────────────────────────────────────┘
```

### 4.3 卡片内部组件

| 元素 | 组件 | 样式/行为 |
|------|------|-----------|
| 卡片容器 | `MudCard` | `Elevation="2"`，`Class="cluster-card"`，高度 100% 填充网格单元 |
| 名称 | `MudText Typo="Typo.h6"` | 单行截断，hover 时整卡 cursor pointer |
| 状态 chip | `MudChip T="string"` `Size="Size.Small"` `Variant="Variant.Filled"` | 在线=Success，离线=Error，未知=Default |
| 上次检查 | `MudText Typo="Typo.caption"` | 显示相对时间（如"3 分钟前"）；当前模型无 `LastCheckedAt`，先预留位置，可用 `CreatedAt` 占位或隐藏，待模型补充后替换 |
| 信息行 | 自定义 div + `MudText` | label 用 `mud-text-secondary`，value 右对齐截断 |
| 刷新按钮 | `MudButton Size="Size.Small"` `StartIcon="Refresh"` | 触发 `RefreshCluster` |
| 编辑按钮 | `MudButton Size="Size.Small"` `StartIcon="Edit"` | 打开 `EditClusterDialog` |
| 删除按钮 | `MudIconButton` 或 `MudButton Size="Size.Small"` `Color="Color.Error"` `StartIcon="DeleteOutline"` | 确认后删除 |

### 4.4 连接方式徽标（未来字段 `ConnectionType`）

待 `ConnectionType` 加入模型后，可在卡片名称右侧、状态 chip 左侧增加一个 `MudChip`：

- `KubeConfig`：图标 `VpnKey` / 文本 "Kubeconfig"
- `Token`：图标 `Token` / 文本 "Token"

颜色用 `Color="Color.Info"` `Variant="Variant.Outlined"`，与状态 chip 区分。

## 5. 表格视图设计

### 5.1 表格组件

使用 `MudTable<T="ClusterInfo">`：

- `Hover="true"` `Dense="true"` `Striped="false"` `FixedHeader="true"`
- `RowClass="cursor-pointer"`，整行点击跳转详情
- 行内操作按钮阻止冒泡

### 5.2 列定义

| 列 | 组件/内容 | 宽度 | 可排序 | 说明 |
|----|-----------|------|--------|------|
| 名称 | `MudText` 加下划线/主色 | flex 1.5 | 是 | 点击跳转 `/clusters/{id}` |
| 状态 | `MudChip` | 80px | 是 | 在线/离线/未知 chip |
| 版本 | `MudText` | 100px | 是 | null 显示 "—" |
| 节点数 | `MudText` 右对齐 | 80px | 是 | 整数 |
| 分组 | `MudText` | 120px | 否 | "未分组" fallback |
| API Server | `MudText` 截断 | flex 2 | 否 | 显示截断，tooltip 显示完整 |
| 创建时间 | `MudText` | 150px | 是 | `yyyy-MM-dd HH:mm` |
| 操作 | `MudIconButton` × 3 | 120px | 否 | 刷新 / 编辑 / 删除 |

### 5.3 表头排序

每列可排序的表头包裹在 `<MudTh><MudTableSortLabel SortBy="...">列名</MudTableSortLabel></MudTh>` 中：

- 名称：`SortBy="x => x.Name"`
- 状态：`SortBy="x => x.Status"`
- 版本：`SortBy="x => x.Version"`
- 节点数：`SortBy="x => x.NodeCount"`
- 创建时间：`SortBy="x => x.CreatedAt"`

表格视图下隐藏卡片视图中的排序下拉，避免两套排序 UI 冲突。

### 5.4 行内操作

| 操作 | 图标 | 行为 |
|------|------|------|
| 刷新 | `Icons.Material.Filled.Refresh` | `@onclick:stopPropagation`，刷新当前集群状态 |
| 编辑 | `Icons.Material.Filled.Edit` | 打开 `EditClusterDialog` |
| 删除 | `Icons.Material.Filled.DeleteOutline` | 确认后删除 |

## 6. 侧边栏设计

保留并小幅优化现有侧边栏，仍作为「分组筛选」独立存在。

### 6.1 结构

```
┌─────────────────────┐
│ 分组          [+]   │  ← group-header
├─────────────────────┤
│ ○ 全部集群      12  │
│ ○ 生产环境       5  │
│ ○ 测试环境       4  │
│ ○ 开发环境       3  │
└─────────────────────┘
```

### 6.2 组件与样式

| 元素 | 组件 | 说明 |
|------|------|------|
| 容器 | 自定义 div `.group-sidebar` | 桌面 260px 宽，sticky top 1rem，最大高度 `calc(100vh - 120px)`，overflow-y auto |
| 头部 | `MudText Typo="Typo.subtitle1"` + `MudIconButton` | 左侧"分组"，右侧新建分组按钮 |
| 分组项 | 自定义 div `.group-item` | flex row，左右分别放名称和数量/删除按钮 |
| 数量徽标 | `MudBadge` | `Color="Color.Primary"`，显示该分组下集群数 |
| 删除按钮 | `MudIconButton` `Color="Color.Error"` | 桌面端 hover 显示；移动端始终显示 |
| 激活态 | CSS active class | 左侧 3px 主色竖线 + 主色 hover 背景 |

### 6.3 交互

- 点击分组项：设置 `selectedGroupId`，工具栏下方的列表实时过滤。
- 点击「全部集群」：`selectedGroupId = null`。
- 删除分组：hover 显示删除图标，点击确认后删除；删除当前选中分组时自动切回「全部集群」。

## 7. 状态设计

### 7.1 加载状态

页面级首次加载或重新加载数据时，在列表区顶部显示一条不确定进度条：

- 组件：`MudProgressLinear Color="Color.Primary" Indeterminate="true"`
- 位置：工具栏下方、列表区上方
- 行为：加载期间列表区不渲染空状态，也不渲染旧数据；进度条下方保留占位高度，避免布局跳动

### 7.2 空状态

区分三种空状态，使用不同的文案与操作：

| 场景 | 条件 | 文案 | 操作 |
|------|------|------|------|
| 无集群数据 | `!loading && clusters.Count == 0` | "暂无集群，点击下方按钮开始管理" | 显示「添加集群」按钮 |
| 筛选结果为空 | `!loading && filteredClusters.Count == 0 && 有筛选条件` | "没有符合当前筛选条件的集群" | 显示「重置筛选」按钮 |
| 无分组 | `groups.Count == 0`（侧边栏内） | 侧边栏内不单独显示空状态，保持「全部集群 0」即可 | 新建分组按钮始终可点 |

空状态容器居中，min-height 300px：

- 组件：`MudText` + `MudIcon`（可选 `Icons.Material.Filled.CloudOff` 或 `SearchOff`） + `MudButton`
- 对齐：`Align="Align.Center"`
- 颜色：文案使用 `mud-text-secondary`

## 8. 响应式设计

### 8.1 断点行为

沿用现有 CSS 的响应式意图，在 MudBlazor 断点基础上细化：

| 断点 | 布局变化 |
|------|----------|
| `xs` (<600px) | 侧边栏与内容区垂直堆叠；侧边栏取消 sticky，宽度 100%；工具栏所有控件垂直堆叠或全宽；卡片单列 |
| `sm` (600-960px) | 侧边栏仍堆叠（或可考虑折叠为顶部横向 chip 列表，本期保持堆叠）；工具栏可两列换行；卡片两列 |
| `md` (960-1280px) | 侧边栏恢复 260px  sticky 左侧；工具栏一行或轻微换行；卡片三列 |
| `lg` (≥1280px) | 侧边栏 260px；工具栏单行；卡片四列；表格所有列完整显示 |

### 8.2 移动端特殊处理

- 删除分组按钮在移动端始终可见（`opacity: 1`），避免 hover 不可用。
- 卡片操作按钮在移动端保持水平排列，必要时换行。
- 表格视图在 xs 下水平滚动：`MudTable` 默认已支持容器滚动，无需额外处理，但应避免列过多导致操作列被挤出。

## 11. 关键布局决策摘要

1. **两行式工具栏**：第一行承载分组标题与「添加集群」按钮，第二行承载搜索/筛选/视图切换/排序，避免首屏信息过载。
2. **分组筛选保持独立侧边栏**：左侧 sticky 侧边栏负责分组切换，与顶部过滤栏 AND 组合，符合现有用户心智。
3. **双视图统一数据源，差异化排序入口**：卡片视图用单一排序下拉；表格视图用 `MudTableSortLabel` 表头排序，两套 UI 不并存。
4. **卡片新增编辑入口与上次检查时间**：在保留刷新/删除的基础上加入编辑按钮，并为 `LastCheckedAt` 预留展示位。
5. **响应式保持现有意图**：桌面端两列 sticky 侧边栏，移动端垂直堆叠；卡片网格 xs=1、sm=2、md=3、lg=4。
