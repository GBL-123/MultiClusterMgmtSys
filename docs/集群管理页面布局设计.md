# 集群管理页面布局设计文档

> 状态：设计阶段（待评审） · 适用页面：`Components/Pages/Clusters.razor`
> 本文档只描述页面布局与视觉结构，不给出具体实现代码。

---

## 1. 设计目标与布局策略

新布局把「浏览 / 定位 / 管理」三种行为分层处理：顶部工具栏集中承载搜索、分组/状态/版本/时间范围过滤，主内容区以表格展示集群。通过单列布局与清晰的区域分工，让最常用的「添加集群」「搜索名称」两项动作在首屏直接可达，同时避免工具栏因控件过多而压过内容。

> 布局变更要点（相对前一版）：
> - **取消左侧分组侧边栏**，分组筛选合并进顶部工具栏，分组的新建/删除改由工具栏按钮 + 「分组管理」对话框承载，页面整体由两列改为单列。
> - **取消卡片视图**，列表区只保留表格视图（`MudTable`），排序由表头 `MudTableSortLabel` 承担，移除视图切换与卡片专属排序下拉。
> - **新增创建时间范围过滤**（开始时间 / 结束时间），与名称/分组/状态/版本并列。

## 2. 整体布局结构

页面在 `MainLayout` 的 `MudMainContent > MudContainer MaxWidth=False` 内渲染，不改变应用外壳（AppBar / Mini Drawer）。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  [MudText h4] 集群管理                                                   │
├─────────────────────────────────────────────────────────────────────────┤
│  ┌───────────────────────────────────────────────────────────────────┐   │
│  │ 标题区：集群数量                              [分组管理] [新建分组] [添加集群] │   │
│  ├───────────────────────────────────────────────────────────────────┤   │
│  │ 工具栏：搜索 | 分组 | 状态 | 版本 | 开始时间 | 结束时间 | [重置]      │   │
│  ├───────────────────────────────────────────────────────────────────┤   │
│  │                                                                   │   │
│  │                       列表区域                                    │   │
│  │                          MudTable                                 │   │
│  │                                                                   │   │
│  └───────────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

### 区域说明

| 区域 | 宽度/行为 | 主要组件 |
|------|-----------|----------|
| 页面标题 | 全宽，位于工具栏之上 | `MudText Typo="Typo.h4"` |
| 内容区 | 全宽单列 | `MudTable` |
| 标题区 | 内容区最上方一行 | `MudText` + `MudButton`（×3） |
| 工具栏 | 标题区下方一行/多行 | `MudTextField` + `MudSelect` + `MudDatePicker` + `MudButton` |
| 列表区 | 工具栏下方，占据内容区剩余空间 | `MudTable` |

## 3. 工具栏区设计

### 3.1 布局安排：两行式

| 行 | 左侧 | 右侧 | 理由 |
|----|------|------|------|
| 第一行 | 集群数量副标题 | 「分组管理」「新建分组」「添加集群」三个按钮 | 让最核心的创建/管理动作常驻右上角，数量信息靠左轻量呈现 |
| 第二行 | 搜索 + 分组 + 状态 + 版本 + 开始时间 + 结束时间 + 重置 | — | 所有过滤控件天然聚类，一行排列；屏幕变窄时自然换行 |

第二行在桌面端尽量一行排列；控件过多或屏幕变窄时允许自然换行（使用 flex wrap）。

### 3.2 控件明细

| 控件 | 组件 | 位置/尺寸 | 行为 |
|------|------|-----------|------|
| 数量副标题 | `MudText Typo="Typo.body2"` | 第一行左侧 | "共 N 个集群"，应用 `mud-text-secondary`；N 为当前过滤后的集群数 |
| 分组管理按钮 | `MudButton` `Variant="Variant.Text"` | 第一行右侧 | `StartIcon="@Icons.Material.Filled.Folder"`，点击打开「分组管理」对话框（见 §5） |
| 新建分组按钮 | `MudButton` `Variant="Variant.Text"` | 第一行右侧 | `StartIcon="@Icons.Material.Filled.CreateNewFolder"`，点击打开 `CreateGroupDialog` |
| 添加集群按钮 | `MudButton` `Variant="Variant.Filled"` `Color="Color.Primary"` | 第一行右侧 | `StartIcon="@Icons.Material.Filled.Add"`，点击打开 `AddClusterDialog` |
| 名称搜索 | `MudTextField` | 第二行最左侧，flex 1，min-width 200px | `Adornment="Adornment.Start"` 搜索图标，`Placeholder="搜索集群名称"`，实时过滤建议防抖 300ms |
| 分组筛选 | `MudSelect<T="int?">` | 第二行，width 160px | 选项：「全部分组」(`null`) + 各分组（`Id`→`Name`）；`Dense="true"`；切换时实时过滤列表 |
| 状态筛选 | `MudSelect<T="ClusterStatus?">` | 第二行，width 140px | 选项：全部 / 在线 / 离线 / 未知；`Dense="true"` |
| 版本筛选 | `MudSelect<T="string">` | 第二行，width 160px | 选项来自当前集群 distinct `Version`（非空），含"未知"代表 null；`Dense="true"` |
| 开始时间 | `MudDatePicker<T="DateTime?">` | 第二行，width 160px | 按集群 `CreatedAt` 过滤；选某日则含当日 00:00 起；留空表示不限下界 |
| 结束时间 | `MudDatePicker<T="DateTime?">` | 第二行，width 160px | 按集群 `CreatedAt` 过滤；选某日则含当日全量（即 `< 次日 00:00`）；留空表示不限上界 |
| 重置按钮 | `MudButton` `Variant="Variant.Text"` `Color="Color.Secondary"` | 第二行，筛选控件右侧 | 清空名称、分组、状态、版本、开始时间、结束时间六个条件 |

### 3.3 过滤组合逻辑

最终结果 = 分组 AND 名称 AND 状态 AND 版本 AND 创建时间范围，六个条件 AND 组合，全部作用于同一 `filteredClusters` 计算源。分组筛选与其他条件地位等同，不再有独立的侧边栏通道。

时间范围边界规则：
- 仅设开始时间：`CreatedAt >= 开始时间`（含当日 00:00）。
- 仅设结束时间：`CreatedAt < 结束时间.AddDays(1)`（含当日全天）。
- 两者皆设：闭区间 `[开始时间当日 00:00, 结束时间次日 00:00)`。
- 两者皆空：不施加时间过滤。

> 说明：`CreatedAt` 以 UTC 存储，`MudDatePicker` 返回本地日期；直接比较在跨时区边界可能差几小时。对内部运维工具影响可忽略，未做时区换算。如需精确可在比较前对选择值做 `ToUniversalTime()` 转换。

## 4. 表格视图设计

列表区只保留表格视图，不再有卡片视图与视图切换控件。

### 4.1 表格组件

使用 `MudTable<T="ClusterViewModel">`：

- `Hover="true"` `Dense="true"` `Striped="false"` `Elevation="0"`
- 行内操作按钮阻止冒泡
- 名称列可点击跳转详情（整行点击未启用，避免与操作列冲突）

### 4.2 列定义

| 列 | 组件/内容 | 宽度 | 可排序 | 说明 |
|----|-----------|------|--------|------|
| 名称 | `MudText` 加下划线/主色 | flex 1.5 | 是 | 点击跳转 `/clusters/{id}` |
| 状态 | `MudChip` | 80px | 是 | 在线/离线/未知 chip |
| 版本 | `MudText` | 100px | 是 | null 显示 "—" |
| 节点数 | `MudText` 右对齐 | 80px | 是 | 整数 |
| 分组 | `MudText` | 120px | 否 | "未分组" fallback |
| API Server | `MudText` 截断 | flex 2 | 否 | 显示截断，tooltip 显示完整 |
| 创建时间 | `MudText` | 150px | 是 | `yyyy-MM-dd HH:mm` |
| 操作 | `MudIconButton` × 3 | 120px | 否 | 刷新 / 编辑 / 删除 |

### 4.3 表头排序

每列可排序的表头包裹在 `<MudTh><MudTableSortLabel T="ClusterViewModel" SortBy="...">列名</MudTableSortLabel></MudTh>` 中：

- 名称：`SortBy="x => x.Name"`
- 状态：`SortBy="x => x.Status"`
- 版本：`SortBy="x => x.Version"`
- 节点数：`SortBy="x => x.NodeCount"`
- 创建时间：`SortBy="x => x.CreatedAt"`

点击表头切换升降序。不再有卡片视图的排序下拉，排序入口唯一。

### 4.4 行内操作

| 操作 | 图标 | 行为 |
|------|------|------|
| 刷新 | `Icons.Material.Filled.Refresh` | `@onclick:stopPropagation`，刷新当前集群状态 |
| 编辑 | `Icons.Material.Filled.Edit` | 打开 `EditClusterDialog` |
| 删除 | `Icons.Material.Filled.DeleteOutline` | 确认后删除 |

## 5. 分组管理设计

取消侧边栏后，分组的新建与删除改由工具栏按钮 + 对话框承载，避免在主页面占用常驻空间。

### 5.1 入口

工具栏第一行右侧的「分组管理」按钮（`Icons.Material.Filled.Folder`）打开「分组管理」对话框；「新建分组」按钮（`Icons.Material.Filled.CreateNewFolder`）直接打开已有的 `CreateGroupDialog`。

### 5.2 「分组管理」对话框结构

```
┌──────────────────────────────────┐
│  分组管理                    [×] │
├──────────────────────────────────┤
│  分组名称              集群数  操作│
│  生产环境                 5   [删除]│
│  测试环境                 4   [删除]│
│  开发环境                 3   [删除]│
├──────────────────────────────────┤
│              [新建分组]   [关闭] │
└──────────────────────────────────┘
```

### 5.3 组件与交互

| 元素 | 组件 | 说明 |
|------|------|------|
| 容器 | `MudDialog` `MaxWidth="MaxWidth.Medium"` `FullWidth="true"` | 复用 MudBlazor Dialog 体系 |
| 分组列表 | `MudTable<ClusterGroupViewModel>` `Dense="true"` `Hover="true"` | 列：分组名称 / 集群数（`ClusterCount`）/ 操作 |
| 删除按钮 | `MudIconButton` `Color="Color.Error"` `Icon="DeleteOutline"` | 点击弹 `ShowMessageBoxAsync` 二次确认；删除当前正在筛选的分组时，关闭对话框后父页面自动把分组筛选重置为「全部分组」 |
| 新建分组按钮 | `MudButton` `Variant="Variant.Text"` `StartIcon="CreateNewFolder"` | 打开 `CreateGroupDialog`；成功后刷新对话框内列表 |
| 关闭按钮 | `MudButton` `Variant="Text"` | 关闭对话框；关闭时若分组有变更（`DialogResult.Ok(groupChanged)`），通知父页面刷新工具栏分组下拉与列表 |

### 5.4 数据来源

对话框注入 `GroupService`，打开时调用 `GetGroupsAsync()` 获取 `List<ClusterGroupViewModel>`；删除调用 `DeleteGroupAsync(id)`，新建后重新拉取。父页面在对话框关闭后（`!result.Canceled`）重新加载分组下拉选项与集群列表，并校验当前 `filterGroupId` 是否仍存在，不存在则置空，保持筛选下拉与数据一致。

## 6. 状态设计

### 6.1 加载状态

页面级首次加载或重新加载数据时，在列表区顶部显示一条不确定进度条：

- 组件：`MudProgressLinear Color="Color.Primary" Indeterminate="true"`
- 位置：工具栏下方、列表区上方
- 行为：加载期间列表区不渲染空状态，也不渲染旧数据；进度条下方保留占位高度，避免布局跳动

### 6.2 空状态

区分两种空状态，使用不同的文案与操作：

| 场景 | 条件 | 文案 | 操作 |
|------|------|------|------|
| 无集群数据 | `!loading && clusters.Count == 0` | "暂无集群，点击下方按钮开始管理" | 显示「添加集群」按钮 |
| 筛选结果为空 | `!loading && filteredClusters.Count == 0 && 有筛选条件` | "没有符合当前筛选条件的集群" | 显示「重置筛选」按钮 |

空状态容器居中，min-height 300px：

- 组件：`MudText` + `MudButton`
- 对齐：`Align="Align.Center"`
- 颜色：文案使用 `mud-text-secondary`

> 分组为空的情况不再单独占位：分组下拉只含「全部分组」一项，「分组管理」对话框内显示"暂无分组，点击新建"即可。

## 7. 响应式设计

### 7.1 断点行为

单列布局，沿用 MudBlazor 断点细化工具栏行为：

| 断点 | 布局变化 |
|------|----------|
| `xs` (<600px) | 工具栏所有控件垂直堆叠或全宽；第一行按钮换行排列；表格水平滚动 |
| `sm` (600-960px) | 工具栏可两列换行；表格水平滚动 |
| `md` (960-1280px) | 工具栏一行或轻微换行；表格所有列完整显示 |
| `lg` (≥1280px) | 工具栏单行；表格所有列完整显示 |

### 7.2 移动端特殊处理

- 第一行三个按钮在移动端允许换行，必要时「分组管理」折叠为图标按钮。
- 表格视图在 xs 下水平滚动：`MudTable` 默认已支持容器滚动，无需额外处理，但应避免列过多导致操作列被挤出。

## 8. 间距与视觉规范

### 8.1 间距

| 元素 | 值 | 说明 |
|------|-----|------|
| 页面标题下边距 | `mb-4` | 与下方工具栏拉开距离 |
| 内容区标题区下边距 | `mb-4` | 标题区与工具栏之间 |
| 工具栏内部控件间隙 | `gap-3` (0.75rem) | 搜索、筛选、日期选择器、按钮之间 |
| 工具栏下边距 | `mb-4` | 工具栏与列表区之间 |

### 8.2 色彩与层次

| 元素 | 色彩/样式 |
|------|-----------|
| 页面背景 | 继承 `MainLayout` 的 `MudContainer` 背景，不额外设置 |
| 页面标题 | `Typo.h4`，主文本色 |
| 数量/标签 | `mud-text-secondary` |
| 状态 chip | Online=Success，Offline=Error，Unknown=Default |
| 操作按钮 | 刷新默认色，编辑默认色，删除 Error |
| 分组管理/新建分组按钮 | `Variant="Variant.Text"`，默认文本色，与「添加集群」主按钮形成主次对比 |

### 8.3 阴影与圆角

| 元素 | 阴影/圆角 |
|------|-----------|
| 按钮 | 使用 MudBlazor 默认圆角，不覆写 |
| 表格 | 无额外阴影，使用 divider 分隔 |
| 对话框 | 继承 `MudDialog` 默认圆角与 elevation |

## 9. 关键布局决策摘要

1. **两行式工具栏**：第一行承载集群数量与「分组管理 / 新建分组 / 添加集群」三个动作按钮，第二行承载搜索/分组/状态/版本/开始时间/结束时间/重置，避免首屏信息过载。
2. **取消侧边栏，分组筛选并入工具栏**：分组作为 `MudSelect` 与名称/状态/版本/时间范围并列，六个条件 AND 组合作用于同一数据源；分组的新建/删除改由「分组管理」对话框承载，主页面不再保留常驻侧边栏。
3. **单一表格视图，表头排序**：取消卡片视图与视图切换，列表区只用 `MudTable`，排序由 `MudTableSortLabel` 表头承担，排序入口唯一。
4. **创建时间范围过滤**：开始/结束时间两个 `MudDatePicker`，按 `CreatedAt` 闭区间过滤，留空表示不限。
5. **响应式单列布局**：桌面与移动端均为单列，工具栏按断点自适应换行；窄屏表格水平滚动。
