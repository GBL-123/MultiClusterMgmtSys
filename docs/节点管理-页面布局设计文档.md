# 节点管理 - 页面布局设计文档

> 状态：设计阶段 · 适用技术：.NET 10 Blazor Server + MudBlazor 9.6
> 本文档仅描述页面布局与组件选型，不给出完整实现代码。

---

## 1. 概述

### 1.1 设计目标

为「节点管理」功能的两张新页面提供与现有页面一致的布局方案：

- **Nodes.razor**：集群维度下的节点列表页，延续 `Clusters.razor` 的「标题 + 摘要/操作 + 工具栏 + 表格」模式。
- **NodeDetail.razor**：单节点详情页，延续 `ClusterDetail.razor` 的「标题 + 返回 + 多卡片分块」模式。

### 1.2 风格基调

- **视觉语言**：复用集群管理已建立的样式——Indigo-Blue 主色、Slate 背景、卡片分块、Dense 表格、小号状态 Chip。
- **密度**：数据密集型运维界面，表格与表单控件使用 `Dense="true"`，工具栏控件紧凑排列。
- **层级**：页面标题 → 上下文摘要/工具栏 → 主内容区（表格或卡片栅格），信息由上至下、由总览到细节递进。
- **一致性原则**：
  - 颜色、圆角、阴影、字重完全遵循《集群管理 UI 主题设计文档》。
  - 表格列标题、单元格留白、可点击链接样式与 `Clusters.razor` 完全一致。
  - 卡片分块、栅格列宽、加载/空/错误占位与 `ClusterDetail.razor` 完全一致。
  - 返回按钮、刷新按钮、状态 Chip 的图标/变体/颜色与现有页面一致。

## 2. 全局约定

### 2.1 栅格与卡片

| 元素 | 约定 |
|------|------|
| 外层栅格 | `<MudGrid Spacing="3">` |
| 卡片 | `<MudCard Elevation="1">`（浅色/暗色均用 1，避免暗色下阴影不可见） |
| 卡片标题 | `<MudCardHeader>` 内左侧 `<MudText Typo="Typo.h6">`；状态 Chip 放右侧 `CardHeaderActions` |
| 卡片内容 | `<MudCardContent>` 内再套 `<MudGrid Spacing="2">` |
| 字段项 | `label` 用 `MudText Typo="Typo.body2" Class="mud-text-secondary"`，`value` 用 `MudText Typo="Typo.body1"` |
| 字段项列宽 | 三列布局为主：`xs="12" sm="6" md="4"`；关键字段（如 Name、UID、长文本）可占 `xs="12"` |

### 2.2 表格约定

| 属性 | 约定 |
|------|------|
| 列表页表格 | `<MudTable Dense="true" Hover="true" Elevation="0">` |
| 详情页内嵌表格 | `<MudTable Dense="true" Hover="true" Striped="true" Elevation="0">` |
| 表头 | 可排序列用 `<MudTableSortLabel>`；不可排序列直接 `<MudTh>` |
| 单元格 | 文本过长用 `Style="max-width:200px; overflow:hidden; text-overflow:ellipsis; white-space:nowrap;"` + `Title` 完整提示 |

### 2.3 状态着色规则

#### 节点状态（Ready / NotReady / Unknown）

| 状态 | MudChip 颜色 | 备注 |
|------|-------------|------|
| Ready | `Color.Success` | 填充变体 `Variant.Filled`，`Size="Size.Small"` |
| NotReady | `Color.Error` | 同上 |
| Unknown | `Color.Default` 或 `Color.Secondary` | 用于信息缺失或异常场景 |

#### Conditions 类型着色建议

| Condition Type | Status=True | Status=False | Status=Unknown |
|----------------|-------------|--------------|----------------|
| Ready | `Success` | `Error` | `Default` |
| MemoryPressure | `Error` | `Success` | `Default` |
| DiskPressure | `Error` | `Success` | `Default` |
| PIDPressure | `Error` | `Success` | `Default` |
| NetworkUnavailable | `Error` | `Success` | `Default` |

> 实现提示：可为 Condition 写一个辅助方法，根据 Type + Status 综合判断颜色；True 对 Ready 是健康，对其他压力类则是不健康。

### 2.4 加载 / 空 / 错误 / 未找到 占位

| 状态 | 处理方式 | 参考来源 |
|------|---------|---------|
| `loading` | 页面级 `<MudProgressLinear Color="Color.Primary" Indeterminate="true" Class="my-4" />` | `Clusters.razor` |
| 空数据 | 居中的 `<MudText Class="mud-text-secondary" Align="Align.Center">` + 可选操作按钮，容器 `min-height:300px` | `Clusters.razor` |
| 未找到 | `<MudCard Class="pa-8" Elevation="2">` 居中提示 + 返回按钮 | `ClusterDetail.razor` |
| 集群不可达 | 在上下文卡片或表格区显示 `MudText Class="mud-text-secondary"` 提示「集群不可达，无法获取节点列表」 | `ClusterDetail.razor` 节点列表 |
| 加载异常 | `Snackbar.Add($"加载失败: {ex.Message}", Severity.Error)`，页面本身保留原内容或显示错误占位 | 现有页面统一做法 |

### 2.5 交互反馈

- **可点击名称**：`Color="Color.Primary" Style="cursor:pointer; text-decoration: underline;"`。
- **刷新按钮处理中态**：按钮 `Disabled="processing"`，按钮内用 `@if(processing){ <MudProgressCircular Size="Size.Small" Indeterminate="true" Class="mr-1" /> }`。
- **图标按钮**：返回/刷新用 `Variant="Variant.Text"`，主要操作用 `Variant="Variant.Filled"`。

## 3. 节点列表页（Nodes.razor）布局设计

路由：`/nodes` 和 `/clusters/{ClusterId:int}/nodes`（双入口）

参数：`[Parameter] public int? ClusterId { get; set; }`

- `/nodes`：从侧边栏「节点管理」进入，左侧显示集群选择栏，右侧显示「请选择集群」空状态。
- `/clusters/{ClusterId:int}/nodes`：从集群详情下钻进入，左侧集群选择栏高亮当前集群，右侧展示该集群节点列表。

### 3.1 页面骨架（双栏结构）

```text

    <MudItem xs="12" md="9" lg="10">  右侧内容区

      3. 工具栏区（搜索 + 刷新，仅 ClusterId 有值时显示）
      4. 状态占位区（未选择集群 / loading / unreachable / empty / not-found）
```

### 3.2 左侧集群选择栏

左侧栏是 `Nodes.razor` 双栏布局的核心导航区，用于在多个集群之间切换。无论通过 `/nodes` 还是 `/clusters/{id}/nodes` 进入，左侧栏始终显示全部集群列表。

#### 组件与结构

```text
<MudItem xs="12" md="3" lg="2">
  <MudCard Elevation="1">
    <MudCardHeader>
      <CardHeaderContent>
        <MudText Typo="Typo.h6">选择集群</MudText>
      </CardHeaderContent>
    </MudCardHeader>
    <MudCardContent>
      <MudTextField T="string"
                    @bind-Value="clusterSearch"
                    Label="搜索集群"
                    Adornment="Adornment.Start"
                    AdornmentIcon="@Icons.Material.Filled.Search"
                    Variant="Variant.Outlined"
                    Margin="Margin.Dense"
                    Class="mb-2" />
      <MudList T="ClusterViewModel" Dense="true" Clickable="true">
        @foreach (var c in filteredClusters)
        {
          <MudListItem OnClick="() => SelectCluster(c.Id)"
                       Class="@(c.Id == ClusterId ? "mud-selected-item" : "")">
            <div class="d-flex align-center justify-space-between">
              <MudText Typo="Typo.body2" Style="@(c.Status == Offline ? "opacity:0.6" : "")">
                @c.Name
              </MudText>
              <MudChip T="string"
                       Size="Size.Small"
                       Color="GetClusterStatusColor(c.Status)"
                       Variant="Variant.Filled">
                @c.StatusText
              </MudChip>
            </div>
          </MudListItem>
        }
      </MudList>
    </MudCardContent>
  </MudCard>
</MudItem>
```

#### 设计要求

| 项 | 说明 |
|----|------|
| 容器 | `MudCard Elevation="1"`，标题「选择集群」用 `Typo.h6` |
| 搜索框 | 可选增强项；`MudTextField` 过滤左侧集群列表（按名称包含匹配） |
| 列表 | `MudList` + `MudListItem`，`Dense="true"`、`Clickable="true"` |
| 集群项内容 | 左侧集群名称，右侧状态 Chip（小号填充） |
| 集群状态色 | Online=`Success`，Offline=`Error`，Unknown=`Default` |
| 当前选中高亮 | `Class="@(c.Id == ClusterId ? "mud-selected-item" : "")"`；也可自定义左侧主色边框 + 浅背景 |
| 离线集群 | 名称可置灰（`opacity:0.6`），但仍可点击；点击后右侧显示「集群不可达」 |
| 点击行为 | `SelectCluster(int id)` → `NavigationManager.NavigateTo($"/clusters/{id}/nodes")` |
| 空状态 | 集群列表为空时显示「暂无集群」 |
| 加载态 | 集群列表加载中显示 `MudProgressLinear` |

> 说明：左侧栏集群列表数据源为 `ClusterService.GetClustersAsync()`，与 `Clusters.razor` 一致。

### 3.3 页面标题 + 返回按钮行

- 左侧：`<MudText Typo="Typo.h4" Class="flex-grow-1">节点管理</MudText>`
- 右侧：返回按钮仅当 `ClusterId.HasValue` 时显示：
  - `<MudButton Variant="Variant.Text" StartIcon="@Icons.Material.Filled.ArrowBack" OnClick="...">返回集群详情</MudButton>`
  - 点击跳转 `/clusters/{ClusterId}`
- 容器：`<div class="d-flex align-center mb-4">`
- 当 `ClusterId is null` 时，标题行右侧不显示返回按钮（因为从侧边栏直接进入）。

### 3.4 顶部上下文摘要区

使用一张 `MudCard` 承载当前集群的摘要信息，让用户明确「我正在看哪个集群」。仅当 `ClusterId.HasValue` 时渲染。

```text
<MudCard Elevation="1">
  <MudCardHeader>
    <CardHeaderContent>
      <MudText Typo="Typo.h6">集群上下文</MudText>
    </CardHeaderContent>
    <CardHeaderActions>
      <MudChip T="string" Size="Size.Small" Color="GetClusterStatusColor(cluster.Status)" Variant="Variant.Filled">
        @cluster.StatusText
      </MudChip>
    </CardHeaderActions>
  </MudCardHeader>
  <MudCardContent>
    <MudGrid Spacing="2">
      <MudItem xs="12" sm="6" md="3"> 名称 </MudItem>
      <MudItem xs="12" sm="6" md="3"> 状态 </MudItem>
      <MudItem xs="12" sm="6" md="3"> 节点数 </MudItem>
      <MudItem xs="12" sm="6" md="3"> API Server </MudItem>
    </MudGrid>
  </MudCardContent>
</MudCard>
```

| 字段 | 列宽 | 渲染 |
|------|------|------|
| 名称 | `xs="12" sm="6" md="3"` | 纯文本 `cluster.Name` |
| 状态 | `xs="12" sm="6" md="3"` | 重复显示状态 Chip（与卡片头部一致，便于小屏下也可见） |
| 节点数 | `xs="12" sm="6" md="3"` | `cluster.NodeCount` |
| API Server | `xs="12" sm="6" md="3"` | 超长省略 + `Title` 提示 |

> 说明：由于左侧集群选择栏已展示集群名称和状态，本卡片可考虑精简为仅保留 API Server、节点数等左侧栏放不下的信息。

### 3.5 工具栏区

与 `Clusters.razor` 第二行工具栏对齐：`<div class="d-flex flex-wrap align-center gap-3 mb-4">`。仅当 `ClusterId.HasValue` 时渲染。

| 控件 | 组件 | 关键属性 |
|------|------|---------|
| 节点名称搜索 | `MudTextField` | `T="string"`, `Label="搜索节点名称"`, `Adornment="Adornment.Start"`, `AdornmentIcon="Search"`, `Variant="Variant.Outlined"`, `Margin="Margin.Dense"`, `Style="min-width:200px; flex:1;"` |
| 状态筛选（可选） | `MudSelect` | `T="string?"`，选项：全部 / Ready / NotReady / Unknown，宽度 140px |
| 刷新按钮 | `MudButton` | `Variant="Variant.Outlined"`, `Color="Color.Primary"`, `StartIcon="Refresh"`, `Disabled="processing"` |

> 说明：返回按钮已上移至「页面标题 + 返回按钮行」。功能设计只要求「名称搜索」，状态筛选可作为增强项保留接口但不必须实现。建议先实现搜索框 + 刷新，留出状态筛选位置。

### 3.7 各降级态

| 场景 | 条件 | 布局占位 |
|------|------|---------|
| 未选择集群 | `ClusterId is null` | 右侧内容区居中显示「请从左侧选择一个集群」+ 引导图标，容器 `min-height:400px`，不渲染标题行/上下文卡片/工具栏/表格 |
| 加载中 | `loading == true` | 页面顶部 `MudProgressLinear`，右侧表格区不渲染 |
| 集群不存在 | `cluster is null` | 右侧居中 `MudCard`：`未找到该集群`，带返回集群列表按钮 |
| 集群不可达 | `cluster is not null && !cluster.IsReachable` | 右侧上下文卡片正常显示集群信息；工具栏禁用刷新或保留刷新但提示失败；表格区显示「集群不可达，无法获取节点列表」 |
| 无节点数据 | `nodes.Count == 0 && cluster.IsReachable` | 右侧表格位置替换为居中 `MudText`：「暂无节点数据」 |
| 筛选结果为空 | `filteredNodes.Count == 0 && nodes.Count > 0` | 与 `Clusters.razor` 一致：「没有符合当前筛选条件的节点」+ 重置按钮 |

## 5. 响应式策略

### 5.1 列表页响应式

- **双栏布局**：
  - 中屏及以上（`md+`）：左侧集群选择栏 `md="3" lg="2"`，右侧内容区 `md="9" lg="10"`，左右并排。
  - 小屏（`<md`）：左侧栏 `xs="12"` 占满宽度，右侧内容区 `xs="12"` 堆叠在下方。
- **小屏优化方案**：小屏下左侧栏可折叠为顶部 `MudSelect` 下拉选择集群（更节省纵向空间）。选择集群后下方展示节点列表。实现时保留 `MudGrid` 结构，通过条件渲染切换左侧栏为 `MudSelect` 或 `MudCard`。
- 标题行：始终 `d-flex align-center`，小屏下按钮文字可能换行；保持按钮文字简短可缓解。
- 工具栏：`flex-wrap`，搜索框 `flex:1` 占满剩余宽度，筛选框固定宽度，小屏自动换行。
- 表格：MudTable 默认横向滚动，所有列保持可见；角色/操作系统列可在极小屏隐藏，但建议保留所有列，因为字段不长。

### 5.2 详情页响应式

- 外层 `MudGrid Spacing="3"`。
- 概要卡片、资源卡片、系统信息卡片、操作卡片始终独占 `xs="12"`。
- 调度信息 / 元数据、地址 / 条件、污点 / 标签、标签 / 注解 均使用 `xs="12" md="6"`：
  - 小屏（<960px）：两卡片上下堆叠。
  - 中屏及以上：左右并排，提高空间利用率。
- 资源容量卡片内的两个子表格：`xs="12" md="6"`，小屏上下堆叠，中屏并排。
- 系统信息字段：`xs="12" sm="6" md="4"`，小屏单列，中屏双列，大屏三列。
- 表格列数较多时（如 Conditions 6 列），保持默认横向滚动；不要为小屏隐藏关键列。

### 5.3 字体与间距

- 标题 `Typo.h4` 在移动端可能偏大，但 MudBlazor 默认响应式已处理；如需更紧凑，可在小屏使用 `Class="mb-2"` 替代 `mb-4`。
- 卡片内字段间距保持 `Spacing="2"`，避免过挤。

## 6. 交互与反馈细节

### 6.1 下钻交互

- 列表页节点名称：`Color="Color.Primary"` + 下划线 + `cursor:pointer`。
- 鼠标悬停：MudBlazor `Hover="true"` 整行背景变化，提示可点击区域。
- 点击：跳转 `/clusters/{ClusterId}/nodes/{NodeName}`。

### 6.2 刷新交互

- 列表页与详情页刷新按钮统一使用 `processing` 标志：

```text
<MudButton Variant="Variant.Outlined"
           Color="Color.Primary"
           StartIcon="@Icons.Material.Filled.Refresh"
           OnClick="Refresh"
           Disabled="processing">
  @if (processing)
  {
    <MudProgressCircular Size="Size.Small" Indeterminate="true" Class="mr-1" />
  }
  刷新
</MudButton>
```

### 6.3 Snackbar 提示

- 加载失败：`Severity.Error`
- 刷新成功：`Severity.Success`（若后续刷新成功有提示需求）
- 节点不存在：可在加载失败时统一提示，或在详情页 `node is null` 的占位中说明。

### 6.4 返回按钮

- 列表页：返回 `/clusters/{ClusterId}`（集群详情）。
- 详情页：返回 `/clusters/{ClusterId}/nodes`（节点列表）。
- 样式统一：`Variant="Variant.Text"`，`StartIcon="ArrowBack"`。

### 7.2 导航菜单说明

`MainLayout.razor` 中已有的 `MudNavLink Href="/nodes"` 即为节点管理侧边栏入口，无需改动。

实现时可放在页面标题上方，使用 `MudBreadcrumbs` 组件；当前可先不加，保持与现有页面一致。

## 8. 设计决策摘要

1. **列表页采用双栏布局**：左侧集群选择栏 + 右侧内容区，支持侧边栏独立入口（`/nodes`）与集群下钻入口（`/clusters/{id}/nodes`）两种进入方式，选中集群后统一为 `/clusters/{id}/nodes`；右侧保留标题 + 集群上下文摘要 + 工具栏 + 表格 + 前端搜索。
2. **详情页沿用 ClusterDetail.razor 模式**：标题 + 返回 + 多卡片栅格分块，字段按语义聚合到不同卡片。
3. **状态色统一**：Ready=Success，NotReady=Error，Unknown=Default/Secondary；Conditions 按 Type+Status 综合着色。
4. **资源 Capacity/Allocatable 并排展示**：在同一卡片内左右两个子表格，便于对比。
5. **字典类字段用表格展示**：Labels / Annotations / Capacity / Allocatable 均用两列 MudTable，保证对齐与可扫描性。
6. **响应式以 md=6 双列为主**：详情页半数卡片并排，小屏自动堆叠；表格保持横向滚动不弃列。
7. **不引入新视觉风格**：所有颜色、圆角、阴影、Chip、按钮、加载占位均复用现有页面约定。
