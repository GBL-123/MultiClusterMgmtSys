# Spec Delta

## ADDED Requirements

### Requirement: 节点就绪趋势

看板 SHALL 展示最近 24 小时的舰队节点就绪趋势:数据全部读自本地节点健康快照,SHALL NOT 发起任何 Kubernetes API 调用。趋势 SHALL 与既有「节点就绪」点值卡并存,SHALL NOT 替代或改变该卡的口径。

趋势曲线的口径 SHALL 为逐快照事件推进的舰队合计阶梯序列:以采集时间排列窗口内的全部快照,任一时刻的就绪/未就绪合计 = 各集群在该时刻之前最近一条快照的就绪数与未就绪数之和;某集群写入新快照时,曲线自该时刻起改用新值。从未成功探测(窗口内无任何快照)的集群 SHALL NOT 参与曲线;窗口内没有任何快照时,趋势区域 SHALL 展示明确的空态,SHALL NOT 展示空曲线。

趋势区域 SHALL 标注统计窗口(24 小时)与曲线各序列的含义(就绪/未就绪),时间与数值 SHALL 使用等宽字体呈现,展示风格遵循全站设计契约。

#### Scenario: 曲线随快照事件推进

- **WHEN** 窗口内集群 A 最后一次快照为 8 节点 6 就绪,随后在 10:05 再次探测成功写入 8 节点 5 就绪,而集群 B 自 09:00 后无新快照(最后一次为 4 节点 4 就绪)
- **THEN** 自 10:05 起曲线值变为就绪 5+4=9、未就绪 3+0=3,10:05 之前曲线值为就绪 6+4=10、未就绪 2+0=2

#### Scenario: 无快照空态

- **WHEN** 最近 24 小时内没有任何集群写入节点健康快照,或所有集群从未被成功探测
- **THEN** 趋势区域展示明确的空态文案,不渲染空曲线

#### Scenario: 零 Kubernetes 调用

- **WHEN** 用户打开看板查看节点就绪趋势
- **THEN** 曲线数据来自本地快照表,本次展示不发起任何 Kubernetes API 调用

#### Scenario: 窗口与序列含义标注

- **WHEN** 趋势区域渲染曲线
- **THEN** 展示「24 小时」窗口标注与就绪/未就绪两个序列的图例说明
